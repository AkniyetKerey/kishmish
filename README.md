# Kish-Mish — сайт-меню с онлайн-заказом

Сайт заведения Kish-Mish по адресу 28-63: меню, корзина и оформление заказа через WhatsApp. Меню и заказы хранятся в Supabase, управление блюдами доступно через отдельную админку.

## Как работает заказ

1. Посетитель сразу видит меню заведения.
2. Добавляет блюда в корзину, выбирает доставку или самовывоз.
3. Сайт рассчитывает стоимость еды, упаковки и доставки.
4. При нажатии «Заказать» сайт пытается сохранить заказ в Supabase, затем открывает WhatsApp заведения с готовым текстом заказа.

Корзина, адрес, тип заказа и тема сохраняются в localStorage браузера. Кнопка «Меню с фото» открывает графическое меню в Canva.

## Управление меню

Откройте `admin.html` и войдите через Supabase Auth. Можно добавлять, переименовывать и удалять категории, менять блюда и цены, временно скрывать позиции кнопкой ❄️. Сложные категории с вариантами напитков редактируются как JSON. Кнопка «Загрузить меню из data.js» заменяет текущее меню локальным набором данных после подтверждения.

Сохранение вызывает функцию базы `replace_branch_menu` с ключом `28-63`. Этот же ключ используется при чтении меню и записи заказов.

## Настройки

В `js/config.js`:

| Константа | Назначение |
|---|---|
| `BRANCH` | Ключ точки обслуживания: `28-63` |
| `WHATSAPP_PHONE` | WhatsApp заведения |
| `PHOTO_MENU_LINK` | Ссылка на меню с фото |
| `CONTAINER_PRICE` | Стоимость контейнера |
| `DELIVERY_COST` | Стоимость доставки и порог скидки |
| `UPSELL_RANGE` | Диапазон суммы для подсказки о скидке на доставку |
| `TRENDING_KEYWORDS` | Названия для блока «В тренде» |

В `js/api.js` заданы URL Supabase, публичный ключ и `USE_SUPABASE = true`. Приложение обращается к таблицам `categories`, `items`, `products`, `product_sizes`, `orders` и функции `replace_branch_menu`. SQL-схема и правила доступа базы в этот репозиторий не включены. Права доступа необходимо настраивать на стороне Supabase.

## Локальная разработка

Проект использует HTML, CSS и обычный JavaScript без сборщика. Откройте папку проекта через локальный HTTP-сервер.

Для работы без базы установите `USE_SUPABASE = false` в `js/api.js`. Меню будет браться из `data.js` или локальных правок админки; заказы в этом режиме в базу не записываются. Локальные правки видны только в текущем браузере.

При изменении JS/CSS увеличивайте `?v=N` у всех локальных подключений в `index.html` и `admin.html` одновременно, чтобы обновить кэш браузеров.
